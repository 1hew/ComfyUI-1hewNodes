# Int Audio Count - 统计非空音频数量

**节点功能：** `Int Audio Count` 从动态 `audio_1..audio_N` 输入中统计音频对象数量。空值判定与 `Any Empty Bool` 一致：`None` 与空容器不计入，非空 AUDIO 字典（标准 `{waveform, sample_rate}`）计为 1。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `audio_1` | 可选 | AUDIO | - | - | 第一个音频输入；连接后前端会自动追加 `audio_2..audio_N` |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `int` | INT | 非空音频输入数量 |

## 功能说明

- 动态输入：连接最后一个 `audio_X` 端口后会自动追加下一个音频端口。
- 空值判定沿用 `Any Empty Bool` 的字典规则：非空 AUDIO 字典计为 1。
- 列表感知：音频列表（OUTPUT_IS_LIST）按非空元素逐项统计。
- 单次统计：列表输入在同一次执行内统计，不会按元素映射成多个整数输出。

## 典型用法

- 可选音频数量：在混音或保存前确认提供了多少条音轨。
- 动态参数：用音频输入数量驱动下游整数参数。

## 注意与建议

- 只判断是否存在，不判断信号内容：静音（全 0 波形）仍会计入，因为其 AUDIO 字典非空。
- 不解码音频，也不检查 `waveform` / `sample_rate`。
- 单个 AUDIO 波形内部的 batch 维度不会拆分；一个音频输入只计 1。
