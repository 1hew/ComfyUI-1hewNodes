# Int Mask Count - 统计有效遮罩数量

**节点功能：** `Int Mask Count` 从动态 `mask_1..mask_N` 输入中统计有效遮罩数量。空输入、空张量与全黑/全 0 遮罩不会计入，判定标准与 `Any Empty Bool` 一致。适合把可选遮罩数量转换为整数参数。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `mask_1` | 可选 | MASK | - | - | 第一个遮罩输入；连接后前端会自动追加 `mask_2..mask_N` |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `int` | INT | 有效遮罩数量 |

## 功能说明

- 动态输入：连接最后一个 `mask_X` 端口后会自动追加下一个遮罩端口。
- 空值判定与 `Any Empty Bool` 一致：`None`、空张量与全 0 项不计入。
- 批次感知：`[B, H, W]` 遮罩按帧逐项统计。
- 列表感知：遮罩列表（OUTPUT_IS_LIST）会被展开，每个元素再按帧逐项统计，可直接连接 `Mask Batch to List`。
- 单次统计：列表输入在同一次执行内统计，不会按元素映射成多个整数输出。

## 典型用法

- 参考遮罩数量：获取实际提供的可选遮罩数量。
- 动态参数：用可用遮罩数量驱动下游整数参数。

## 注意与建议

- 故意绘制的全 0 遮罩会被视为空，与 `Any Empty Bool` 行为一致。
- 只读取张量内容，不做缩放、裁剪或解码。
