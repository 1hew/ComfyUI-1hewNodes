# String Ratio Doubao Seedream 5.0 Pro - 豆包 Seedream 5.0 Pro 比例选择器

**节点功能：** `String Ratio Doubao Seedream 5.0 Pro` 为每张输入图像输出最接近的 Doubao Seedream 5.0 Pro 支持比例字符串；如果未连接图像，则直接输出手动选择的比例。与 1hewOffice 的 `Doubao Seedream 5.0 Pro` API 节点成对使用。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `selection` | - | COMBO | `1:1` | `21:9` / `16:9` / `3:2` / `4:3` / `1:1` / `3:4` / `2:3` / `9:16` | 手动选择的 Doubao Seedream 5.0 Pro 比例预设；未连接 `image` 时直接输出此值 |
| `image` | 可选 | IMAGE | - | - | 输入图像批次，用于逐张推断最接近的支持比例 |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `string` | STRING | 比例字符串结果；批量输入时按批次顺序以换行拼接输出 |

## 功能说明

- Doubao Seedream 5.0 Pro 比例集：`21:9`、`16:9`、`3:2`、`4:3`、`1:1`、`3:4`、`2:3`、`9:16`，共 8 个。
- 图像驱动推断：基于对数比例差匹配每张输入图最接近的预设宽高比。
- 手动回退：未连接图像时直接透传手动选择的比例。
- 批处理友好：支持图像批次输入，每张图输出一行比例字符串。

## 典型用法

- 用在需要比例字符串输入的 Doubao Seedream 5.0 Pro 图像节点前：把本节点 `string` 输出接到 API 节点的 `aspect_ratio` 入端。
- 当你希望下游固定使用某个比例时，可以不连接 `image`，直接输出选定值。
- 图生图/参考图场景：把同一张参考图同时接到本节点 `image` 和 API 节点的 `image_1`，让 API 节点使用与参考图一致的比例。

## 注意与建议

- 这个节点只输出比例字符串，不会修改图像尺寸，也不会决定最终像素；出图像素由 API 节点的 `resolution`（`1k` / `1.5k` / `2k`）与比例查官方尺寸表决定。
- 比例集合**逐项等同**于 1hewOffice 的 `Doubao Seedream 5.0 Pro` API 节点中 `DoubaoSeedream50Pro.ASPECT_RATIO_OPTIONS` 去掉 `auto` 后的 8 项，已逐项核对一致；该 API 节点属于 1hewOffice，其源码不在本仓库内。
- 这里不提供 `auto`：`auto` 由 API 节点自己按参考图推断，本节点输出的是可直接使用的具体比例。
- 该 API 节点**没有 `get_image_size` 入端**，因此文生图（无参考图）时请直接调 API 节点的 `aspect_ratio`；本节点主要用于有图像输入时把比例吸附到官方支持的 8 档。
- 返回的比例为按对数比例差最接近的预设项，极端比例（如 `3:1`、`1:3`）会被吸附到最接近的一档。
