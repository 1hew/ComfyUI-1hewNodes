# Multi Image Overlay - 多图层叠加

**节点功能：** `Multi Image Overlay` 按顺序依次叠加多个图层。RGBA 输入使用 alpha 通道进行正常的图层合成，RGB 输入视为不透明图层。任一输入带 alpha 时，节点会自动按 RGBA 处理并输出 RGBA。支持动态输入端口 `image_1..image_N`、多种尺寸适应模式，以及两种批量模式（`parallel` / `stack`）。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `fit_mode` | - | COMBO | `center` | `top_left` / `center` / `stretch` | 尺寸适应模式 |
| `color` | - | STRING | `1.0` | 灰度/HEX/RGB | 当合成结果无 alpha（输入全为 RGB）时使用的背景色 |
| `batch_mode` | - | COMBO | `parallel` | `parallel` / `stack` | 批量处理方式。`parallel` 按对应批次索引逐帧合成；`stack` 将每个输入批次的每一帧都作为一层，输出单张分层预览图 |
| `image_1..image_N` | - | IMAGE | - | - | 动态输入的图像图层，`image_1` 为最上层，数字越大越靠底层 |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `image` | IMAGE | 叠加合成结果；`stack` 模式下输出单张预览，`parallel` 模式下输出批次 |

## 功能说明

- 动态端口：以 `image_` 开头的输入端口支持自动扩展，`image_1` 为最上层，编号越大越靠底层。
- 尺寸对齐：以最底层图像的尺寸为基准画布尺寸。
- 通道规则：任一输入带 alpha 时，所有图层都会按 RGBA 参与合成，输出自动保留 alpha。
- 适应模式：
  - `center`：居中放置，超出部分裁剪，不足部分透明。
  - `top_left`：左上角对齐放置。
  - `stretch`：拉伸至画布尺寸。
- 批量模式：
  - `parallel`（默认）：将较小的批次广播对齐，按对应批次索引并行合成，`image_1` 在最上、`image_N` 在最下。
  - `stack`：将每个输入批次的每一帧都当作一层，输出单张预览图；同一批次内第一帧位于最上层。
- Alpha 合成：正确处理 RGBA 图像的预乘 alpha 混合。RGB 图像视为完全不透明。

## 典型用法

- 图像合成：将带有透明背景的多个元素（如贴纸、水印、前景主体）叠加到背景图上。
- 批量叠加：使用 `batch_mode=parallel` 对多个批次的对应帧进行合成（较小批次自动广播对齐到最大批次）。
- 单张预览：使用 `batch_mode=stack` 将每个输入的所有帧展平为一张分层预览图。

## 注意与建议

- 数字越大的输入越适合作为背景或底图；`image_1` 更适合作为最上层元素。
- 如果希望结果保持透明信息，只需保证任一输入本身带有 alpha。
