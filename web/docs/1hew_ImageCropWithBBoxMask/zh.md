# Image Crop With BBox Mask - 图像遮罩智能裁切

**节点功能：** 根据遮罩（Mask）的边界框（Bounding Box）智能裁切图像，支持多种比例控制、尺寸约束和批量处理。同时输出裁切后的图像、对应的遮罩以及原始位置的边界框遮罩，便于后续还原。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `image` | 必需 | IMAGE | - | - | 待裁切的原图像 |
| `mask` | 必需 | MASK | - | - | 定义裁切主体的遮罩 |
| `preset_ratio` | - | COMBO | `mask` | `mask` / `image` / `auto` / `9:16` / `2:3` / `3:4` / `4:5` / `1:1` / `5:4` / `4:3` / `3:2` / `16:9` / `21:9` | 目标纵横比预设。`mask`跟随遮罩; `image`跟随原图; `auto`按遮罩自适应构图（忽略离群噪点，`scale_strength` 从贴遮罩过渡到近似全图） |
| `get_crop_ratio` | 可选 | IMAGE | - | - | 可选参考图像。若连接，将自动匹配该图像的宽高比，覆盖 `preset_ratio` |
| `scale_strength` | - | FLOAT | 0.0 | 0.0-1.0 | 缩放强度。`auto` 下 `0` = 刚好装下遮罩、`1` ≈ 全图，中间按对数等比过渡；其它模式在尺寸档位间取位；`crop_to_side` 非 `None` 时不生效 |
| `crop_to_side` | - | COMBO | `None` | `None` / `longest` / `shortest` / `width` / `height` | 目标边长控制模式 |
| `crop_to_length` | - | INT | 1024 | 8-8192 | 目标边长的数值 |
| `divisible_by` | - | INT | 8 | 1-1024 | 输出尺寸整除约束（通常用于模型输入对齐） |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `cropped_image` | IMAGE | 裁切并调整大小后的图像 |
| `bbox_mask` | MASK | 原始图像尺寸的遮罩，白色区域表示裁切发生的具体位置 |
| `cropped_mask` | MASK | 与裁切图像对应的遮罩 |

## 功能说明

- **智能比例控制**：
  - `mask`：尽可能贴合遮罩主体的比例。
  - `auto`：按遮罩自适应，不怕长条图和脏遮罩 ——
    1) 先忽略稀疏离群噪点：只丢掉比最密行/列轻 10 倍、且累计不超过总量 1% 的边，实心主体的边缘不会被削掉；
    2) 以去噪后 bbox 的比例为基准，与最近标准比例的线性偏差 ≤30% 时才吸附（得到 4:3 / 16:9 这类整齐比例），否则保留遮罩比例，细长主体不会被 16:9 之类的固定比例压成小窄条；
    3) 最小裁剪框刚好含住 bbox（对齐 `divisible_by`）并且必然能放进原图，不会像固定比例那样“装不下就整幅返回”；
    4) `scale_strength` 是取景权重：`0` 恰好装下遮罩（遮罩比例、主体占满画面），`1` 是原图能提供的最大对齐框（≈ 全图、原图比例）；中间**在对数尺度上等比放大**（每 0.1 是固定倍率），宽高各自插值，所以比例从遮罩比例平滑过渡到原图比例。例：1663×521 里一个 431px 的圆 + `divisible_by=32`，`0` / `0.5` / `1` 分别得到 448×448、864×480、1632×512；
    5) 裁剪框以遮罩 bbox 为中心，越界时向图内平移，所以遮罩靠边时会自动把空旷一侧的背景补进来；`crop_to_side` / `crop_to_length` 非 `None` 时由它们接管尺寸（仍按 auto 比例取档），`scale_strength` 不参与。
  - `get_crop_ratio`：通过输入图像动态设定目标比例，实现“以图定形”。
- **尺寸约束与调整**：
  - `scale_strength`：`auto` 下 `0`→`1` 从“遮罩紧贴”过渡到“近似全图”（比例同时过渡）；其它模式下保持比例、只向外扩展。
  - `crop_to_side`/`crop_to_length`：直接控制输出图像的物理分辨率（如固定长边为 1024）。
  - `divisible_by`：确保输出宽高符合特定倍数（如 SDXL 需要 8 倍数）。
- **批量处理**：支持 Image 和 Mask 的批次输入，若批次大小不一致会自动广播对齐。

## 典型用法

- **局部重绘预处理**：利用遮罩提取主体并裁切，进行局部放大或重绘，再利用 `bbox_mask` 贴回原图。
- **数据集制作**：将主体从大图中批量裁切出来，并统一缩放到指定尺寸（如 512x512 或 1024x1024）。

## 注意与建议

- 连接 `get_crop_ratio` 时，`preset_ratio`（含 `auto`）的设置将被忽略。
- `auto` 忽略掉的噪点不会被裁进来，也不会落在 `bbox_mask` 内，贴回原图时该区域保持不变；如果这些点本身是有效内容，请改用 `mask` 或明确的比例。
- `auto` 的 `1.0` 受 `divisible_by` 约束，会略小于原图（1663×521、32 倍数时是 1632×512），这是为了保持模型输入对齐。
- 旧版 `auto`（按原图比例吸附标准比例）已并入本模式：现在的 `auto` 以遮罩为主，只有 `scale_strength=1` 才过渡到原图比例。使用过旧 `auto` 的工作流重新打开后输出会按新语义变化，属预期。
- 若遮罩为空或无效，节点将返回全黑或全白的默认图像以避免报错。
