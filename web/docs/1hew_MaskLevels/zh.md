# Mask Levels - 遮罩色阶

**节点功能：** `Mask Levels` 对灰度遮罩做“色阶（Levels）”调整，把 0–255 的灰度区间按 `black_point` / `white_point` 重新映射：小于等于 `black_point` 的值压到 0，大于等于 `white_point` 的值拉到 255，中间做线性插值过渡。当两点重合时退化为二值阈值。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `mask` | - | MASK | - | - | 输入遮罩，支持 2D、`[B,H,W]` 或 `[B,H,W,C]` |
| `black_point` | - | INT | 0 | 0–255（步长 1） | 黑点；灰度小于等于该值（归一化后）的像素输出为 0 |
| `white_point` | - | INT | 255 | 0–255（步长 1） | 白点；灰度大于等于该值的像素输出为 255（即 1.0） |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `mask` | MASK | 色阶调整后的遮罩，值域 0–1 |

## 功能说明

- 线性拉伸：中间区间 `(black_point, white_point)` 做线性插值并夹取到 `[0, 1]`。
- 反转效果：当 `black_point > white_point` 时映射斜率为负，自然得到反相效果。
- 二值退化：`black_point == white_point` 时退化为二值阈值，`>=` 该值输出 1，否则输出 0。
- 形状兼容：自动处理 2D、`[B,H,W]`、`[B,H,W,C]` 输入（4D 取最后一维的第一个通道）。
- 空输入安全：非法形状返回 `[0,64,64]` 空遮罩，不报错。

## 典型用法

- 提纯遮罩：用黑点/白点压缩噪声、放大对比，把软遮罩转成更干净的范围。
- 反相遮罩：设置 `black_point > white_point` 直接反转遮罩。

## 注意与建议

- 默认 `black_point=0`、`white_point=255` 相当于原样透传（整体线性映射到 0–1）。
- `black_point=3`、`white_point=235` 时，0–3 → 0，235–255 → 1，中间线性过渡。
