# String Random - 文本随机选取

**节点功能：** `String Random` 使用常见分隔符把 `custom_text` 拆分为多个候选项，再用给定的 `seed` 随机选择其中一项并输出，适合用于随机化提示词或参数。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `custom_text` | - | STRING | ``（空） | -（多行） | 包含候选项的文本，按分隔线、换行、`。`/`.`、`；`/`;` 或 `，`/`,` 拆分 |
| `seed` | - | INT | 42 | 0–1125899906842624 | 用于可复现随机选取的 RNG 种子 |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `string` | STRING | 从文本中随机选出的候选项 |

## 功能说明

- 分隔符优先级：先按分隔线（`---`）拆分，其次换行，再次 `。`/`.`，然后 `；`/`;`，最后 `，`/`,`。
- 引号修剪：每项首尾成对的单/双引号会被去除。
- 可复现：相同 `seed` 下选取结果确定。
- 空输入处理：空文本输出空字符串。

## 典型用法

- 在多个候选短语之间随机化提示词片段。
- 在批量或迭代流程中随机选取风格关键词或参数值。

## 注意与建议

- 各项会去除首尾空白，空项在随机选取前被丢弃。
- `seed` 同时用于输出的 UI 文本，使选中结果可见。
