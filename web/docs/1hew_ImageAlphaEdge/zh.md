# Image Alpha Edge - alpha 边缘收边/扩边与羽化

**节点功能：** `Image Alpha Edge` 用于调整带 alpha 图像的不透明区域：先向内收边或向外扩边，再对边缘做羽化。收边/扩边是灰度形态学，matte 自带的抗锯齿会被完整保留。它专门用来清理抠图后的毛边——向内收边把被旧背景污染的半透明边缘像素直接裁掉，羽化重建平滑过渡；并在羽化前固定把不透明区域的颜色向过渡带扩散，使羽化后的过渡带不会出现暗边或彩边。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `image` | - | IMAGE | - | - | 输入图像，支持单图或批量；有 alpha（≥4 通道）时使用 alpha，RGB/灰度输入按完全不透明处理 |
| `edge` | - | INT | 0 | -256–256（步长 1） | 带符号的边缘调整（像素）：负值向内收缩，正值向外扩张；0 = 不做任何边缘调整。用灰度 min/max 滤波实现，保留 matte 的亚像素过渡 |
| `feather` | - | FLOAT | 0.0 | 0–256（步长 0.1） | 收边/扩边之后对 alpha 做高斯羽化的半径（sigma） |

## 收边为什么不会产生锯齿

`edge` 直接作用在**灰度 alpha** 上做 min / max 滤波（灰度形态学），而不是先把 alpha 二值化再腐蚀：

- 对局部线性的软边（抠图模型输出的 matte 通常就是 1–3px 的斜坡），半径为 r 的圆盘 min 滤波**恰好等于把该斜坡平移 r 像素**；
- 因此 alpha 的每一条等值线都被整体平移 r 像素——边收掉了，过渡带的亚像素信息完整保留；
- 硬边输入（纯 0/1 遮罩）的结果与旧的二值形态学**逐像素完全相同**，只是没有抗锯齿可保留。

实测对比（半径 40 的圆，`edge = -5`，`feather = 0`，理想半径 35）：

| 方案 | 轮廓抖动 | 相对理想圆最大偏差 | 灰阶数 |
| ---- | -------- | ------------------ | ------ |
| 二值化 + erode（旧行为） | 0.0430 | 0.77 px | 2 |
| 灰度 min 滤波（现在） | **0.0034** | **0.39 px** | 69 |

轮廓抖动 = 相邻角度之间轮廓半径变化的均值，越小越平滑。

如果输入本身就是纯硬边遮罩，收边后仍是硬边——此时用 `feather` 重新生成过渡带即可。

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `image` | IMAGE | alpha 已收边/扩边并羽化后的 RGBA 图像 |
| `mask` | MASK | 处理后的 alpha，可继续交给遮罩类节点使用 |

## 功能说明

- 抗锯齿：`edge` 是灰度形态学，收边后 matte 原有的亚像素过渡完整保留（旧的二值化会把软边打成 1px 台阶）。
- 带符号的边缘控制：一个参数同时覆盖向内收边（负值）与向外扩边（正值）。
- 去毛边：`edge < 0` 时被污染的边缘带是“裁掉”而不是“混合”，这是清理抠图毛边最可靠的方式。
- 内置去污染：羽化前会用**最近实心不透明像素**的颜色填充过渡带（固定行为，没有开关），避免羽化过渡带重新引入旧背景色。取色源要求 `alpha ≥ 0.9`，这样软边自身被污染的半透明像素不会把背景色继续往外扩散。
- 固定处理顺序：收边/扩边 → RGB 外扩 → 羽化。
- 兼容软遮罩：`edge = 0` 时保留原始软 alpha（不做任何阈值化）。
- 职责单一：只做边缘，不碰孔洞填充——填孔属于遮罩修补，请用专门的遮罩节点。
- 批量支持：输入为 image batch 时逐张处理，并同步输出 `image` 与 `mask`。
- 原样透传：`edge = 0`、`feather = 0` 时，输入原样返回（此时不做任何颜色外扩）。

## 典型用法

- 抠图后去毛边：`edge` 设为约 `-2`～`-5`、`feather` 设为 `1`～`3`，把被污染的边缘裁掉并保留柔和过渡。
- 想去掉外圈虚边：直接用 `edge` 收边（例如 `-1`～`-2`）即可。
- 避免轮廓变大：收边量至少取羽化量的 2 倍左右，羽化过渡带就会留在原始轮廓内部。
- 扩张选区：使用正的 `edge` 把不透明区域向外扩展后再羽化。
- 保留原始软边：`edge = 0`，只调 `feather`。

## 注意与建议

- `edge` 不会把软边打硬：灰度形态学保留过渡带，所以头发、烟雾、运动模糊这类软遮罩也能直接收边。硬边遮罩收边后仍是硬边，用 `feather` 生成过渡带。
- 颜色外扩是内置的固定步骤，没有开关：它只在 `feather > 0` 时执行，取色源是收边/扩边之后 `alpha ≥ 0.9` 的实心区，填充范围限于羽化模糊能触及的带（约 `4 × feather` 像素），更远处的透明像素保留原始 RGB。如果整张 matte 最亮都不到 0.9（整体偏淡），则跳过外扩，避免把污染色扩散出去。
- 它改的是 RGB 数据本身：过渡带内原本是旧背景色的透明像素会被替换成最近的主体颜色。如果必须保留那些像素的原始 RGB，请在它之后再用原图补回。
- 关掉它并不会“更干净”，只会让羽化带露出旧背景色形成彩边——实测红主体 + 蓝背景时，不做外扩的蓝色泄漏峰值可达 +0.23。修复取色源后，1～10px 各种软边的泄漏实测都是 0.0000。
- 孔洞填充不在本节点职责内：本节点只平移 alpha 的等值线，不会去修补内部孔洞。需要填孔请先用遮罩类节点处理，再接入本节点。
- `feather` 越大耗时越高；在 2048×2048 图像上半径 256 仍能在一秒内完成。
- 无 alpha 的输入会返回全不透明的 `mask` 和 RGBA 图像，因此可以安全地插入任意位置。
