# String Resolution GPT Image 2.0 - GPT Image 2.0 分辨率选择器

**节点功能：** `String Resolution GPT Image 2.0` 根据输入图像面积输出最接近的 GPT Image 2.0 分辨率档位标签（`1k` / `2k` / `4k`）；如果未连接图像，则直接输出手动选择的标签。与 GPT Image 2.0 成对使用。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `selection` | - | COMBO | `1k` | `1k` / `2k` / `4k` | 手动选择的 GPT Image 2.0 分辨率标签；未连接 `image` 时直接输出此值 |
| `image` | 可选 | IMAGE | - | - | 输入图像批次，用于逐张推断最接近的分辨率档位 |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `string` | STRING | 分辨率标签字符串；批量输入时按批次顺序以换行拼接输出 |

## 档位与目标面积

| 档位 | 1:1 官方尺寸 | 目标面积（像素） |
| ---- | ------------ | ---------------- |
| `1k` | `1024x1024` | 1,048,576 |
| `2k` | `2048x2048` | 4,194,304 |
| `4k` | `3840x2160`（1:1 为 `2880x2880`） | 8,294,400 |

## 功能说明

- GPT Image 2.0 档位：`1k` / `2k` / `4k`，按各档 1:1 官方尺寸的面积作为目标值。
- 面积匹配：按图像总像素面积在各档位目标面积中选择最近值（对数距离）。
- 手动回退：未连接图像时直接透传手动选择的标签。
- 支持批处理：图像批次中的每张图都会输出一行分辨率标签。

## 典型用法

- 在需要分辨率字符串参数的 GPT Image 2.0 节点前，把图像尺寸转换成分辨率标签，接到 API 节点的 `resolution` 入端。
- 不连接 `image` 时，可直接当作固定分辨率字符串选择器使用。

## 注意与建议

- 匹配依据是总像素面积，不考虑具体宽高比。
- 目标面积逐项对应 1hewOffice 的 `GPTImage20.MAX_PIXELS_BY_RESOLUTION`（1k=1024²、2k=2048²、4k=3840x2160，与 4k 的 1:1 尺寸 2880x2880 同面积）；该来源属于 1hewOffice，其源码不在本仓库内。
- 该节点只输出字符串标签，不会修改图像尺寸。
