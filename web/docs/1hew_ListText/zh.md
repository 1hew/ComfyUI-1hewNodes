# List Text - 列表项前后缀

**节点功能：** `List Text` 为列表中的每一项添加前缀和后缀，并输出列表。它与 `Text List to String` 使用相同的 `prefix` / `suffix` 输入，区别在于输出：`Text List to String` 把所有项拼接成一个字符串，而 `List Text` 保留每项一个字符串，便于接入下一个列表节点。

## 输入

| 参数名称 | 插槽 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | ---- | -------- | ------ | -------- | ---- |
| `text_list` | 可选 | * | - | - | 要处理的项；可以是列表、单个值或嵌套列表（摊平一层） |
| `prefix` | - | STRING | `` | - | 加在每一项前面的文字 |
| `suffix` | - | STRING | `` | - | 加在每一项后面的文字 |

## 输出

| 输出名称 | 数据类型 | 描述 |
| -------- | -------- | ---- |
| `text_list` | STRING 列表 | 按顺序每项一个处理后的字符串 |

## 示例

| `text_list` | `prefix` | `suffix` | 输出 |
| ----------- | -------- | -------- | ---- |
| `["cat", "dog"]` | `a ` | ` !` | `["a cat !", "a dog !"]` |
| `[["x", "y"], "z"]` | `` | `` | `["x", "y", "z"]` |
| `[1, 2]` | `#` | `` | `["#1", "#2"]` |

## 注意事项

- 非字符串的项会先用 `str()` 转成文字，再加前后缀。
- 未连接任何项时，输出为空列表。
- 前后缀是原样文字，这里不处理转义字符，与 `Text List to String` 一致。
