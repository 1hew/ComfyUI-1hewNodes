# Int Video Count - 统计已连接视频数量

**节点功能：** `Int Video Count` 统计动态 `video_1..video_N` 输入中的已连接视频对象数量，适合将可选视频输入数量转换为整数参数。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `video_1` | - | VIDEO | - | - | 首个视频输入；前端会按连接情况动态追加 `video_2..video_N`。 |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `int` | INT | 已连接的视频数量。 |

## 功能说明

- 动态输入：连接最后一个 `video_X` 后会自动追加下一个视频端口。
- 空输入：未连接的视频输入不会计数。
- 有序收集：按照视频输入名称中的数字后缀处理动态输入。

## 典型用法

- 可选视频数量：将已连接的视频数量输出给后续整数控制参数。
- 动态工作流：根据视频数量控制视频批次或参考视频处理流程。

## 注意与建议

- 每个非 `None` 的视频输入计为一个已连接视频。
- 本节点只统计已连接的视频对象，不检查视频内部的帧内容。
