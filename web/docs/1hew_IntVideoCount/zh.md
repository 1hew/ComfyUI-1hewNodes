# Int Video Count - 统计非空视频数量

**节点功能：** `Int Video Count` 统计动态 `video_1..video_N` 输入中的非空视频对象数量。空值判定与 `Any Empty Bool` 一致，`None` 与空值不会计入；适合将可选视频输入数量转换为整数参数。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `video_1` | 可选 | VIDEO | - | - | 首个视频输入；前端会按连接情况动态追加 `video_2..video_N`。 |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `int` | INT | 非空视频数量。 |

## 功能说明

- 动态输入：连接最后一个 `video_X` 后会自动追加下一个视频端口。
- 空值判定：与 `Any Empty Bool` 一致，`None` 与空值不会计入。
- 有序收集：按照视频输入名称中的数字后缀处理动态输入。
- 列表感知：列表输出（OUTPUT_IS_LIST）会被展开，每个非空元素计为 1。

## 典型用法

- 可选视频数量：将非空视频数量输出给后续整数控制参数。
- 动态工作流：根据视频数量控制视频批次或参考视频处理流程。

## 注意与建议

- 每个非空视频输入计为 1；空字典或空容器不会计入。
- 只判断是否存在，不检查视频内部的帧内容。
