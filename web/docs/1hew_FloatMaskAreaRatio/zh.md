# Float Mask Area Ratio - 遮罩面积占整张图的比例（0–1 浮点数）

**节点功能：** `Float Mask Area Ratio` 统计遮罩覆盖整张图像的面积比例，输出 `0.0–1.0` 的浮点数，默认保留 2 位小数。遮罩的软值按权重计算（`0.5` 的像素按半个像素计入），因此羽化和抗锯齿边缘得到的是真实覆盖率，而不是按整像素放大。适合把遮罩转换成阈值判断、强度缩放、分支或数值汇报所需的浮点参数。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `mask` | - | MASK | - | - | 待统计的遮罩（或遮罩批次）；以其自身 `H×W` 作为整张图，批次按帧取平均。 |
| `round` | - | INT | `2` | `0–10` | 输出比例保留的小数位数；`0` 时四舍五入到整数（`0.0` 或 `1.0`）。 |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `float` | FLOAT | 遮罩覆盖整张图的比例，按 `round` 位小数四舍五入（`0.0–1.0`）。 |

## 功能说明

- 面积比例：`float` 输出为 `Σ mask / (B × H × W)`，即遮罩权重的均值。
- 精度控制：默认 2 位小数，通过 `round` 可在 `0–10` 之间调整。
- 软值感知：部分透明/羽化像素按权重计入，模糊与抗锯齿不会虚增面积。
- 批次感知：`[B, H, W]` 批次只输出一个平均覆盖率。
- 空值安全：`None`、空张量与非遮罩输入返回 `0.0`。
- 越界保护：取值超出 `0–1` 时先钳制再求平均。

## 典型用法

- 阈值分支：当主体占画面比例超过设定值时走不同分支。
- 强度缩放：用主体占比驱动降噪或混合强度。
- 数值汇报：用一个数字概括遮罩占画面的多少。

## 注意与建议

- 以遮罩自身分辨率作为整张图，因此整幅遮罩即使被缩小（如 latent 尺寸）也得到相同比例。
- 全黑遮罩返回 `0.0`，全白遮罩返回 `1.0`。
- 对二值遮罩而言，结果就是前景像素数 ÷ 总像素数。
- `round` 与 `Range Mapping` 的同名输入保持一致（名称与 `0–10` 范围），便于跨节点统一小数控制。
