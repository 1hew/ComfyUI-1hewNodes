# List Math Expression - 列表逐项数学运算

**节点功能：** `List Math Expression` 是把核心 `Math Expression` 应用到列表上的节点。表达式语法、函数集合与结果检查都与核心节点一致，区别在于每个输入都是列表，表达式按位置逐项计算，输出也是列表。通常与 `Text Path Extract`（列表形式的 `value`）和 `Text Path Replace`（列表形式的 `replace`）配合使用。

## 输入

| 参数名称 | 插槽 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | ---- | -------- | ------ | -------- | ---- |
| `expression` | - | STRING | `a` | 多行 | 计算公式，按位置逐项求值。默认 `a` 即第一个输入，只接一个端口时也能直接工作 |
| `a`、`b`、`c`… | 可选 | * | - | - | 列表（或单个值）；每连接一个就自动长出下一个字母端口，端口名就是表达式里用的名字。 |

## 输出

| 输出名称 | 数据类型 | 描述 |
| -------- | -------- | ---- |
| `FLOAT` | FLOAT 列表 | 每个位置结果的浮点数 |
| `INT` | INT 列表 | 每个位置结果截断后的整数 |
| `BOOL` | BOOLEAN 列表 | 每个位置结果的真假值 |

## 长度对齐规则

| 输入长度 | 结果 |
| -------- | ---- |
| 全部相等，如 3 与 3 | 按位置一一配对计算：第 0 项与第 0 项，第 1 项与第 1 项… |
| 某个输入长度为 1 | 该值广播到所有位置 |
| 单个值（非列表） | 视为长度为 1 |
| 其他组合，如 3 与 2 | 报错“输入长度不一致”，不执行任何计算 |

## 表达式

- 语法与 `Math Expression` 相同：`+ - * / // % **`、括号、比较运算。
- 函数：`sum` `min` `max` `abs` `round` `pow` `sqrt` `ceil` `floor` `log` `log2` `log10` `sin` `cos` `tan` `int` `float`。
- `values` 表示当前位置所有输入组成的列表，例如 `sum(values)`。
- 以上集合之外的内容（导入、属性访问、文件访问等）会被表达式求值器拒绝。
- 结果必须是数值。字符串结果会报错；布尔结果视为数值（`True` = 1）。
- `pow` 的指数超过 4000 会被拒绝，与核心节点的上限一致。

## 典型用法

- 每个索引加 1：`Text Path Extract`（`layers[*].index`）→ `a + 1` → `Text Path Replace`（`layers[*].index`）。
- 两个列表逐项相加：`a = [1, 2, 3]`，`b = [10, 20, 30]`，`a + b` 得到 `[11, 22, 33]`。
- 用单个值缩放整个列表：`b` 只接一个值，`a * b` 把每个元素乘以它。

## 注意事项

- 每个端口固定自己的字母：`b` 未连接时，`c` 依然是 `c`，表达式不用改。
- 节点一次接收每个完整列表（`is_input_list`），ComfyUI 不会对每个元素单独执行它。
- 表达式只在 `simpleeval` 的限制下运行，公式请只写算术。
