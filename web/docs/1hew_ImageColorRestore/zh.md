# Image Color Restore - 参考颜色还原

**节点功能：** `Image Color Restore` 将已对齐的 AI 编辑图的颜色还原到原始参考图，并在物体被移除/遮挡产生的接缝区域做局部平滑。使用可信的仿射颜色拟合与连续接缝场（关闭了结构未变化遮罩清理），适合“局部编辑 + 全局轻微色偏”的还原场景。移植自 ComfyUI-RH-Nodes 的 `Reference Color Restore (Occlusion Seam Advanced) V0.8`。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `edit_image` | - | IMAGE | - | - | AI 编辑后的图像；需大致纯色背景，并与 `org_image` 像素对齐（尺寸不一致时自动缩放到参考图尺寸） |
| `org_image` | - | IMAGE | - | - | 对齐后的原图/参考图，作为颜色来源（无纯色背景要求） |
| `background_threshold` | - | FLOAT | 0.0 | 0–80（步长 0.1） | 前景/背景分割的 LAB 距离阈值；`0` 表示自动。前景占比需落在 0.5%–80%，否则报错 |
| `unchanged_threshold` | - | FLOAT | 10.0 | 0–80（步长 0.1） | 判定“未变化”像素的最大 RGB 残差（0–255）；`0` 表示自动。越大越激进地还原参考图 |
| `seam_max_distance` | - | FLOAT | 96.0 | 1–1024（步长 1） | 从可信未变化区域向外传播的最大距离（px） |
| `seam_decay` | - | FLOAT | 64.0 | 1–1024（步长 1） | 距离衰减系数 `exp(-d/decay)`；越大传播越远 |
| `seam_residual_blur` | - | FLOAT | 24.0 | 0.1–128（步长 0.5） | 平滑残差场的高斯 sigma |
| `seam_color_sigma` | - | FLOAT | 20.0 | 0.1–128（步长 0.5） | Lab 颜色相似度门控 sigma，只向颜色相近的区域传播 |
| `occlusion_residual_blur` | - | FLOAT | 48.0 | 0–128（步长 0.5） | 仅在检测到的遮挡区域使用的额外残差模糊；`0` 关闭局部处理 |
| `occlusion_bridge_width` | - | FLOAT | 48.0 | 0–128（步长 0.5） | 遮挡检测的桥接/影响宽度；`0` 关闭局部处理 |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `corrected_image` | IMAGE | 颜色还原后的图像；`edit_image` 含 alpha 时保留该通道 |
| `safe_unchanged_mask` | MASK | 被判定为“未变化”且可信的遮罩，可用于诊断或后续合成 |

## 功能说明

- 颜色拟合：仅在可信未变化像素上做仿射（含二次项）颜色拟合，避免被真实编辑区域污染。
- 接缝平滑：在物体移除/遮挡产生的接缝处使用连续的接缝场做局部平滑。
- alpha 保留：还原只作用于 RGB，`edit_image` 的 alpha 通道保持不变。
- 批次兼容：支持批次输入；两批次数量不等时，若一方为单张则广播到全部帧。
- 安全失败：前景分割不满足 0.5%–80% 或可信未变化占比过低时抛错，避免输出被破坏。

## 典型用法

- 将局部重绘/AI 编辑的结果还原回原图色调，同时保留新增内容。
- 处理编辑模型在局部修改之外产生的轻微全局色偏。
- 与 `Image Align Change Mask` 配合：先对齐，再用本节点还原颜色。

## 注意与建议

- `edit_image` 必须把主体放在大致纯色背景上，否则前景分割（进而整个拟合）会失败。
- 两图需基本像素对齐；尺寸不同时 `edit_image` 会被缩放到 `org_image` 尺寸。
- 默认参数已适配大多数情况；出现颜色还原过度时可调低 `unchanged_threshold`（`0` 为自动）。
