# Video to Image - 提取图像与视频信息

**节点功能：** `Video to Image` 从 ComfyUI `VIDEO` 对象中提取图像帧、音频、FPS 和帧数。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `video` | - | VIDEO | - | - | 输入的 ComfyUI 视频对象 |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `image` | IMAGE | 视频中的图像帧，以图像批次形式输出 |
| `audio` | AUDIO | 视频中的音频数据；存在音频时输出 |
| `fps` | FLOAT | 视频帧率 |
| `frame_count` | INT | 输出图像批次中的帧数 |

## 功能说明

- 提取视频图像帧时不会重新解码视频。
- 保留视频对象提供的图像批次、音频数据和帧率。
- 输出图像帧数量。
- 未连接视频或没有有效帧时输出空结果。

## 典型用法

- 将 `Load Video` 连接到 `Video to Image`，使用图像节点处理视频帧。
- 将 `URL to Video` 连接到 `Video to Image`，提取下载视频中的图像帧。
- 使用 `fps` 和 `frame_count` 进行时间和批次大小计算。

## 注意与建议

- 输入必须是带有 `get_components()` 方法的 ComfyUI `VIDEO` 对象。
- 本节点不会修改帧率、帧选择或图像格式。
- 没有音频流的视频可能不会输出音频。
