# Image Shift - 平移与接缝遮罩

**节点功能：** `Image Shift` 将整批图像按 `shift_x` / `shift_y` 像素平移。开启 `cyclic` 时移出画布的部分从对侧卷回，可直接得到可平铺的结果；关闭时用 `background_color` 填充空出的区域。除平移后的图像外，还会输出平移后的 `mask` 与经过模糊的接缝 `border_mask`（原图四条边，也就是卷回后的接缝），可直接接到重绘 / inpaint 节点。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `image` | - | IMAGE | - | - | 待平移的图像批次；支持并保持 1、3、4（RGBA）通道 |
| `shift_x` | - | INT | 256 | -9999–9999 | 水平位移；正值使内容向右移动 |
| `shift_y` | - | INT | 256 | -9999–9999 | 垂直位移；正值使内容向下移动 |
| `border_mask_width` | - | INT | 20 | 0–999 | 接缝带宽度（像素），会被限制在短边的一半以内 |
| `border_mask_blur` | - | INT | 12 | 0–999 | 平移后对接缝带做高斯模糊的半径 |
| `pad` | - | INT | 0 | 0–8192 | 四边各环向扩展的像素数（`0` = 关闭），让顶到画布边界的接缝在 inpaint 前获得边界外上下文 |
| `cyclic` | - | BOOLEAN | true | - | 出界部分是否循环卷回，关闭时改用背景色填充 |
| `background_color` | - | STRING | `1.0` | - | `cyclic` 关闭时的填充，写法与 `Image Alpha Split` 相同：0–1 灰度、`#RRGGBB`、颜色名、单字母、`r,g,b`，或 `sm` 智能背景 |
| `mask` | - | MASK | - | - | 随图像一起平移的伴随遮罩，不影响图像本身，只决定 `mask` 输出；未连接时输出 alpha（RGBA）或全白遮罩。单帧自动广播，尺寸不同先缩放。 |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `image` | IMAGE | 平移后的图像批次，尺寸与通道数与输入一致 |
| `mask` | MASK | 平移后的遮罩：来自 `mask` 输入、alpha 通道或全白遮罩；非循环模式下空出区域为 0，可当作有效性遮罩使用 |
| `border_mask` | MASK | 平移后标记原图边框位置的模糊接缝带 |
| `pad_mask` | MASK | 标记 `pad` 补出来的那圈边框（1 = 环向复制区）；`pad = 0` 时全 0 |

## 功能说明

- 循环卷回用 `torch.roll` 对整批一次完成，1024² 图约 1 毫秒，输入在 GPU 上时结果也留在 GPU。
- 颜色输入与 `Image Alpha Split` 一致：两个节点调用 `utils/_alpha_ops.py` 里同一个函数，`background_color` 接受的写法（含 `sm`）完全相同。
- 非循环边界像素级精确：位移 `N` 就只留下 `N` 像素填充，位移为 0 时严格等于原图（LayerStyle 参考实现因用了严格 `>` 比较会多留 1 像素）。
- 保留通道数：RGBA 输入保留 alpha，灰度保持单通道，填充色会按通道数适配。
- 遮罩按批次匹配：单张自动广播、整批逐帧对应、数量不足时沿用最后一帧、尺寸不同时先缩放到图像尺寸。
- 接缝带直接按像素切片生成，`border_mask_width` 就是真实宽度（参考实现用 `expand` + `resize`，实际宽度会缩为 `W / (W + 2·width)`，非方形画布上还会横纵不一致）。
- 接缝带只由画布尺寸与位移决定，因此整批只计算一次后共享。
- 可选环向扩展：`pad > 0` 时把平移后的 `image`、`mask`、`border_mask` 一起按 `pad` 像素环向扩展，顶在画布边界上的接缝端点就变成内部接缝，inpaint 能拿到两侧上下文。

## 背景色（与 Image Alpha Split 相同）

`background_color` 使用与 `Image Alpha Split` 完全相同的解析实现（`utils/_alpha_ops.py`），两个节点接受同一组写法：

| 写法 | 示例 | 说明 |
| ---- | ---- | ---- |
| 灰度（0–1） | `1.0`、`0.5`、`0.0` | 0 黑 … 1 白；默认 `1.0` |
| 十六进制 | `#FF00FF`、`#0f0` | 3 位或 6 位 |
| 颜色名 / 单字母 | `red`、`r`、`w` | PIL 颜色名；`r` 红、`k` 黑 |
| RGB | `128,192,255` 或 `0.5,0.7,0.9` | 自动识别 0–255 与 0–1 |
| `sm` | - | 智能背景：逐帧在 黑 / 白 / `#808080` 中选择，保证 alpha 主体可辨识，与 `Image Alpha Split` 同一算法；无 alpha 的 RGB 输入得到白色 |

无法识别的值退回白色，与 `Image Alpha Split` 一致。

## 典型用法

- **无缝贴图：** 开启 `cyclic` 并平移约半幅宽高，把 `pad` 设为“接缝带 + 余量”（例如 `border_mask_width = 100` 时取 `320`），让四个顶到画布边界的端点拿到边界外上下文；用 `border_mask` 重绘 / inpaint，再用 `Image Edge Crop/Pad`（`uniform_amount = -pad`）裁回，最后平移回去或直接平铺。
- **图层错位：** 平移合成图层，并用 `mask` 输出作为其有效区域遮罩（非循环模式会用 `background_color` 填补空位）。
- **纹理滚动：** 在 `cyclic` 开启时动画化 `shift_x`，即可滚动可平铺纹理而不出现边框。

## 注意与建议

- `border_mask_blur` 建议不超过 `border_mask_width` 的一半；模糊远大于带宽时接缝带会整体低于 50%，重绘遮罩就失效了。
- 循环模式下接缝位于原图左右（或上下）边缘卷回相接处，正好被 `border_mask` 覆盖；非循环模式下该带仍然标记原图边框，而不是新内容边界。
- 允许位移超过画布尺寸：循环模式按尺寸取模卷回，非循环模式则只剩 `background_color`。
- 接缝十字必然顶到画布四边：这四个端点正是接缝延续到相邻瓦片的位置，必须用 `pad > 0` 环向扩展后再 inpaint；直接在原画布上补，端点只有单侧上下文，平铺会出现错位。
- `pad` 要覆盖接缝带再加余量：半幅偏移时带宽是 `2 × border_mask_width`，`border_mask_width = 100` 时至少 `pad ≥ 200`，实际取 `320` 更稳。
