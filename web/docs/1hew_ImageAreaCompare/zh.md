# Image Area Compare - 图像像素面积比较

**节点功能：** `Image Area Compare` 比较两个 IMAGE 输入的像素面积（`宽 × 高`，即总像素数），并根据选择的比较符输出布尔值。它是 `Int Number Compare` 的图像版本。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `a` | - | IMAGE | - | - | 左侧图像，其 `宽 × 高` 作为左值 |
| `operator` | - | COMBO | `==` | `==`、`!=`、`>`、`>=`、`<`、`<=` | 比较运算符 |
| `b` | - | IMAGE | - | - | 右侧图像，其 `宽 × 高` 作为右值 |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `bool` | BOOLEAN | 比较结果，条件成立为 `true`，否则为 `false` |

## 功能说明

- 像素面积比较：参与比较的是两张图的总像素数（`宽 × 高`），不是文件体积，也不是画面主体的有效面积。
- 比较符与 `Int Number Compare` 一致：等于、不等于、大于、大于等于、小于、小于等于。
- 与批次无关：同一 IMAGE 批次内所有帧尺寸相同，批次大小不影响面积。
- 异常保护：输入为空、非图像或发生异常时输出 `false`。

## 典型用法

- 分辨率判断：在选择放大路径前，判断一张图是否比另一张大。
- 分支控制：将输出连接到 `Any Switch Bool`，为高分辨率与低分辨率图像分流。

## 注意与建议

- 面积由张量形状（`高 × 宽`）计算，与颜色通道和 alpha 无关。
- 可与 `Image Minimum Area` 搭配，用于确认图像是否达到了最小面积要求。
