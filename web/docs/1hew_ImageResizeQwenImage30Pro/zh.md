# Image Resize Qwen Image 3.0 Pro - Qwen Image 3.0 Pro 尺寸适配

**节点功能：** `Image Resize Qwen Image 3.0 Pro` 用于将输入图像/遮罩调整到 Qwen Image 3.0 Pro 可接受的尺寸。`auto` 会先按输入面积确定 `1k`/`2k` 档位、再在该档内选最接近比例的预设（`auto (1k)` 等则固定档位）；`dynamic*` 则按 Qwen Image 3.0 Pro 规则尽量保持输入比例并动态缩放。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `preset_size` | - | COMBO | `auto (2k)` | `auto*` / `dynamic*` / 各预设尺寸项 | 目标尺寸选择；`auto` 按输入面积定档后选最近比例，`auto (1k)` 等固定档位，`dynamic*` 保持输入比例动态缩放，具体预设项输出固定尺寸 |
| `fit` | - | COMBO | `crop` | `crop` / `pad` / `stretch` | 适应模式：裁剪、填充、拉伸 |
| `pad_color` | - | STRING | `1.0` | 灰度/HEX/RGB/颜色名/`edge`/`average`/`extend`/`mirror` | `pad` 模式背景填充策略 |
| `image` | 可选 | IMAGE | - | - | 输入图像批次 |
| `mask` | 可选 | MASK | - | - | 输入遮罩批次，可与图像同步变换 |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `image` | IMAGE | 调整后的图像批次 |
| `mask` | MASK | 与输出尺寸对齐的遮罩批次 |
| `native_image` | IMAGE | 主输出的原生分辨率副本；内容、裁剪与填充一致，仅分辨率不同 |
| `native_mask` | MASK | 与 `native_image` 对齐的遮罩 |

## 功能说明

- 预设 auto：`auto` 会先按输入面积确定 `1k` / `2k` 档位，再在该档内匹配最接近比例的尺寸；`auto (1k)` / `auto (2k)` 则固定在该档内匹配比例。
- 动态 dynamic：`dynamic` 会按输入面积选择最接近的 `1k` / `2k` 档位并保持输入比例动态缩放；`dynamic (1k)` / `dynamic (2k)` 会固定档位。
- 固定预设：提供 `1k`、`2k` 两档下常用比例的稳定尺寸，适合需要明确输出尺寸的工作流。
- Qwen Image 3.0 Pro 规则：动态尺寸与预设尺寸都会按 16 像素对齐、安全比例范围（1:8 ~ 8:1）与最大边 4096 等规则处理。
- 支持无图像或无遮罩场景：只输入 `image` 或 `mask` 也可执行；都为空时输出目标尺寸背景图与全白遮罩。
- 三种适配模式：
  - `crop`：先按比例中心裁剪再缩放到目标尺寸。
  - `pad`：先按比例缩放再居中填充到目标尺寸。
  - `stretch`：直接拉伸到目标尺寸。

## 典型用法

- 送入 Qwen Image 3.0 Pro 文生图前对齐到常见预设：`preset_size=auto (2k)`，`fit=crop`。
- 尽量保持输入原始比例：`preset_size=dynamic (2k)`，`fit=pad` 或 `fit=crop`。
- 需要固定横图尺寸：选择 `[2k] 2560x1440 (16:9)` 或 `[1k] 1280x720 (16:9)`。
- 保留完整画面并补边：`fit=pad`，按需要设置 `pad_color`（如 `1.0`、`#000000`、`mirror`）。
- 只用遮罩生成对应画布：只连接 `mask` 输入，节点会生成对应背景图并输出对齐后的遮罩。

## 注意与建议

- 这张表是按 Qwen Image 3.0 Pro 尺寸规则归纳出的节点固定预设，不是官方固定枚举表。
- Qwen Image 3.0 Pro 官方限制：像素面积 `512x512` ~ `2048x2048`、宽高比 `1:8` ~ `8:1`，因此本节点**不提供 `4k` 档**。
- 本节点的 `1k` / `2k` 预设与 `Image Resize GPT Image 2.0` **完全一致**（后者多出的 `4k` 档在 Qwen 上不可用）。
- 与 `Image Resize GPT Image 2.0` 的差异仅在动态参数：安全比例范围为 `1:8` ~ `8:1`（GPT 为 `1:3` ~ `3:1`），最大边为 `4096`（GPT 为 `3840`）。
- 注意：Qwen Image 3.0 Pro 的**图生图（edits）会忽略 `size` 参数**，输出分辨率由上游决定（约 2K）。此时本节点可用于调整参考图比例，从而**间接影响输出比例**。
- `auto` 会先按输入面积定档，再从对应档的表里挑最近比例；`auto (1k)` 等固定档位；`dynamic*` 会按输入比例动态计算。
