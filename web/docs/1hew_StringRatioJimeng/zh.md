# String Ratio Jimeng - 即梦比例选择器

**节点功能：** `String Ratio Jimeng` 为每张输入图像输出最接近的即梦支持比例字符串；如果未连接图像，则直接输出手动选择的比例。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `selection` | - | COMBO | `1:1` | `21:9` / `16:9` / `3:2` / `4:3` / `1:1` / `3:4` / `2:3` / `9:16` | 手动选择的即梦比例预设；未连接 `image` 时直接输出此值 |
| `image` | 可选 | IMAGE | - | - | 输入图像批次，用于逐张推断最接近的支持比例 |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `string` | STRING | 比例字符串结果；批量输入时按批次顺序以换行拼接输出 |

## 功能说明

- 即梦比例集：`21:9`、`16:9`、`3:2`、`4:3`、`1:1`、`3:4`、`2:3`、`9:16`。
- 图像驱动推断：基于对数比例差匹配每张输入图最接近的预设宽高比。
- 手动回退：未连接图像时直接透传手动选择的比例。
- 批处理友好：支持图像批次输入，每张图输出一行比例字符串。

## 典型用法

- 用在需要比例字符串输入的即梦图像节点前。
- 当你希望下游固定使用某个比例时，可以不连接 `image`，直接输出选定值。

## 注意与建议

- 这个节点只输出比例字符串，不会修改图像尺寸。
- 返回的比例为按对数比例差最接近的预设项。
