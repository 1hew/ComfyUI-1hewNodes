# Image Blur - 高斯模糊

**节点功能：** `Image Blur` 对整张图像逐通道做高斯模糊，行为对标 LayerStyle 的 `LayerFilter: Gaussian Blur V2`。`blur` 为 `0` 时原图直接透传。按 batch 逐帧处理，保持通道数不变。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `image` | - | IMAGE | - | - | 待模糊的输入图像批次 |
| `blur` | - | FLOAT | 20.0 | 0.0–1000.0（步长 0.01） | 高斯模糊半径；`0` 或负值时原图直接透传 |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `image` | IMAGE | 模糊后的图像批次 |

## 功能说明

- 小数半径：`blur` 为 FLOAT，语义上更接近 V2 版本的高斯模糊。
- 零值透传：`blur <= 0` 时直接返回原图，不做处理。
- 逐通道模糊：对每个通道独立模糊后再拼接，保持通道数不变。
- 批处理友好：对批次中的每一帧独立处理。

## 典型用法

- 合成前对图像进行柔化或背景虚化。
- 在图像流程中对整图做一次快速的平滑处理。

## 注意与建议

- 模糊通过 PIL 的 `ImageFilter.GaussianBlur` 按指定半径实现。
- 半径越大耗时越长，常规平滑建议使用较小到中等的值。
