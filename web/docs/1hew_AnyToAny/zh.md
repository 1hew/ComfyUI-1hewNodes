# Any to Any - 通配类型适配

**节点功能：** `Any to Any` 将任意输入值原样透传，并把输入、输出都声明为通配类型（`*`），让声明类型不同的节点也能互相连接，避免 ComfyUI 因类型不匹配而拒绝连线。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `any` | 可选 | ANY（`*`） | - | - | 需要透传的值，可接受任意上游输出类型 |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `any` | ANY（`*`） | 原样输出的同一个值，以通配类型呈现 |

## 功能说明

- 类型擦除透传：数值原样转发，不做类型转换或数据转换。
- 两端通配：具体类型的输出可以连到 `any`，`any` 也可以连到具体类型的输入。
- 可选输入：未连接时输出 `None`。
- 类型无关：可透传张量、模型、条件、音视频对象、字符串、数值、列表以及自定义载荷。

## 典型用法

- 上游输出类型与下游声明类型不一致时，用本节点作为中转。
- 把具体类型的输出接到无法直接连接的控件（widget）或 `COMBO` 输入端。
- 搭建或调试工作流时快速绕过严格的连线类型检查。

## 注意与建议

- 本节点只解除连线类型限制，不会真正转换数据；请确认下游节点能够处理上游传入的对象。
- 需要实际的数据转换（例如图像转遮罩）时，请使用对应的转换节点。
- 下游收到的是原始对象，因此通配连线不能修正形状、通道或格式上的不匹配。
