# Text System Prompt - 读取内置系统提示词

**节点功能：** `Text System Prompt` 把一条已存好的系统提示词以纯字符串输出，让任意 LLM 节点或需要提示词的下游节点直接取用，不必把长文本粘贴到参数框里。提示词以 `.txt` 文件存放在 `utils/system_prompt/`，下拉列表与目录结构一一对应，选中哪条就原样输出哪条的正文。

## 输入

| 参数名称 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | ------ | -------- | ---- |
| `file` | COMBO | 第一项 | `utils/system_prompt/` 下的每个 `.txt` 文件 | 形如 `<模型>/[<语言>] <名称>`，即文件相对 `utils/system_prompt/` 的路径去掉 `.txt` 后缀 |

## 输出

| 输出名称 | 数据类型 | 描述 |
| -------- | -------- | ---- |
| `string` | STRING | 所选提示词正文，原样输出：不去首尾空白、不做占位符替换，只丢弃 UTF-8 BOM |

## 目录结构

```
utils/system_prompt/
└── <模型文件夹>/
    └── [<语言>] <提示词名>.txt
```

| 文件 | 下拉项 |
| ---- | ------ |
| `qwen_image_2.1/[en] edit.txt` | `qwen_image_2.1/[en] edit` |
| `qwen_image_2.1/[en] t2i.txt` | `qwen_image_2.1/[en] t2i` |

## 功能说明

- **按模型分目录：** 每个目标模型一个文件夹，保留官方写法（含点号，如 `qwen_image_2.1`）；它们只是普通目录，不是 Python 包，点号不影响加载。
- **语言写在文件名里：** `[en]` / `[cn]` 是文件名的一部分，一个文件只存一种语言，中英两版就是两个文件。
- **启动时注册：** 扩展加载时扫描一次并把键表缓存下来，之后展开下拉不产生额外开销。
- **按 mtime 读取：** 改已有条目的正文，下次执行即生效、不必重启 ComfyUI；新增或删除文件则要重载，因为下拉在启动时就固定了。
- **跳过规则：** 名字以 `_` 或 `.` 开头的文件和目录不参与扫描，可以在正文旁放说明文件而不污染下拉。
- **不阻塞工作流：** 目录为空时显示一条占位项并输出空字符串；键不存在时打印警告并输出 `""`。

## 典型用法

- 把整理好的系统提示词直接接到 LLM 节点或提示词增强节点。
- 同一提示词按模型、按语言各存一份，在工作流里选版本，而不是每次改一大段文本框。
- 需要和用户输入拼接时，配合 `String Join Multi` 或 `Text Prefix Suffix` 使用。

## 注意与建议

- 下拉是单层列表，条目里的 `/` 只是目录分隔符，不是二级控件。
- 正文按 UTF-8 读取，BOM 会被去掉，其余内容逐字节保留。
- 不要随意改名：下拉值会存进工作流，改名后旧工作流会退回选中第一项。
- 这个目录只收自包含的提示词：不依赖别的节点注入 caption，不带抽取用的包裹标记，也不带某个采样器专用的 JSON 外壳。
- 内置的 Qwen-Image-2.1 正文改编自 [benjiyaya/ComfyUI-Qwen-Image-2.1-Prompt-Enhancer](https://github.com/benjiyaya/ComfyUI-Qwen-Image-2.1-Prompt-Enhancer)（MIT）。上游返回 JSON 加比例字段，本地版已改成纯文本输出，可直接接到编码器。
- 正文不做裁剪：若文件结尾是 "The user's edit instruction to rewrite is:" 这样的引导句，它属于输出的一部分，预期下一轮再说用户需求。
