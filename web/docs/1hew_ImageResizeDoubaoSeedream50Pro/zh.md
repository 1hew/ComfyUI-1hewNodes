# Image Resize Doubao Seedream 5.0 Pro - Doubao Seedream 5.0 Pro 尺寸适配

**节点功能：** `Image Resize Doubao Seedream 5.0 Pro` 用于把输入图像/遮罩调整到 Doubao Seedream 5.0 Pro 官方尺寸表里的精确像素，与 1hewOffice 的 `Doubao Seedream 5.0 Pro` API 节点成对使用。`auto` 会先按输入面积确定 `1k`/`1.5k`/`2k` 档位、再在该档内选最接近比例的预设（`auto (1k)` 等则固定档位）；`dynamic*` 则尽量保持输入比例动态缩放。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `preset_size` | - | COMBO | `auto (2k)` | `auto*` / `dynamic*` / 各预设尺寸项 | 目标尺寸选择；`auto` 按输入面积定档后选最近比例，`auto (1k)` 等固定档位，`dynamic*` 保持输入比例动态缩放，具体预设项输出固定尺寸 |
| `fit` | - | COMBO | `crop` | `crop` / `pad` / `stretch` | 适应模式：裁剪、填充、拉伸 |
| `pad_color` | - | STRING | `1.0` | 灰度/HEX/RGB/颜色名/`edge`/`average`/`extend`/`mirror` | `pad` 模式背景填充策略 |
| `image` | 可选 | IMAGE | - | - | 输入图像批次 |
| `mask` | 可选 | MASK | - | - | 输入遮罩批次，可与图像同步变换 |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `image` | IMAGE | 调整后的图像批次 |
| `mask` | MASK | 与输出尺寸对齐的遮罩批次 |
| `native_image` | IMAGE | 主输出的原生分辨率副本；内容、裁剪与填充一致，仅分辨率不同 |
| `native_mask` | MASK | 与 `native_image` 对齐的遮罩 |

## 功能说明

- 预设 auto：`auto` 先按输入面积确定 `1k` / `1.5k` / `2k` 档位，再在该档内匹配最接近比例的尺寸；`auto (1k)` / `auto (1.5k)` / `auto (2k)` 固定在该档内匹配比例。
- 动态 dynamic：`dynamic` 按输入面积选择最接近档位并保持输入比例动态缩放；`dynamic (1k)` 等固定档位。
- 固定预设：提供 `1k`、`1.5k`、`2k` 三档下 8 个比例的稳定尺寸，适合需要明确输出尺寸的工作流。
- 规则：动态尺寸按 16 像素对齐、安全比例范围 `1:16` ~ `16:1`、最大边 `4096` 处理。
- 支持无图像或无遮罩场景：只输入 `image` 或 `mask` 也可执行；都为空时输出目标尺寸背景图与全白遮罩。
- 三种适配模式：
  - `crop`：先按比例中心裁剪再缩放到目标尺寸。
  - `pad`：先按比例缩放再居中填充到目标尺寸。
  - `stretch`：直接拉伸到目标尺寸。

## 典型用法

- 图生图/参考图对齐到官方尺寸：本节点 `preset_size` 选一档 → `image` 接到 API 节点的 `image_1`，API 节点设 `aspect_ratio=auto`、`resolution` 选与本节点相同的档位，出图尺寸即可与本节点完全一致。
- 需要固定横图尺寸：选择 `[2k] 2816x1584 (16:9)` 或 `[1k] 1424x800 (16:9)`。
- 保留完整画面并补边：`fit=pad`，按需要设置 `pad_color`（如 `1.0`、`#000000`、`mirror`）。
- 只用遮罩生成对应画布：只连接 `mask` 输入，节点会生成对应背景图并输出对齐后的遮罩。

## 固定预设尺寸表

| 比例 | 1k 尺寸 | 1.5k 尺寸 | 2k 尺寸 |
| ---- | ------ | -------- | ------ |
| `1:1` | `1024x1024` | `1536x1536` | `2048x2048` |
| `4:3` | `1152x864` | `1792x1344` | `2368x1776` |
| `3:4` | `864x1152` | `1344x1792` | `1776x2368` |
| `16:9` | `1424x800` | `2048x1152` | `2816x1584` |
| `9:16` | `800x1424` | `1152x2048` | `1584x2816` |
| `3:2` | `1248x832` | `1872x1248` | `2496x1664` |
| `2:3` | `832x1248` | `1248x1872` | `1664x2496` |
| `21:9` | `1568x672` | `2352x1008` | `3136x1344` |

## 注意与建议

- 这张表**逐项等同**于 1hewOffice 的 `Doubao Seedream 5.0 Pro` API 节点中 `DoubaoSeedream50Pro` 的 `SIZE_MAP` 类属性，共 3 档 × 8 比例 = 24 项，已逐项核对一致；该 API 节点属于 1hewOffice，其源码不在本仓库内。
- Doubao Seedream 5.0 Pro 的 API 节点**没有 `get_image_size` 入端**（不同于 Qwen Image 3.0 Pro / GPT Image 2.0）。因此本节点只能把 `image` 接到 API 节点的 `image_1`，让 `aspect_ratio=auto` 从参考图推断比例；**文生图（无参考图）时无法用本节点指定出图尺寸**，请直接调 API 节点的 `aspect_ratio` + `resolution`。
- 比例只有 8 个：`1:1` / `4:3` / `3:4` / `16:9` / `9:16` / `3:2` / `2:3` / `21:9`（与 API 节点 `aspect_ratio` 选项一致），没有 `5:4`、`3:1`、`2:1` 等。
- `dynamic*` 会产出不在官方表内的任意尺寸；接回 API 节点后，`auto` 会把比例吸附到最近的官方档位并改用表内尺寸，所以**出图尺寸不会与本节点完全相同**（比例大致保留）。要精确复现请用 `auto (...)` 或具体预设项。
- 本节点的 `1k` / `2k` 预设与 Qwen Image 3.0 Pro / GPT Image 2.0 的**不同**（各家官方尺寸表不同），请勿混用。
