# Int Text Count - 统计非空文本类输入数量

**节点功能：** `Int Text Count` 从动态通配端口 `text_1..text_N` 中统计非空的 `STRING` / `INT` / `FLOAT` 输入。空值判定与 `Any Empty Bool` 一致：空白字符串、`0` / `0.0`、`False` 视为空，`True` 计为 1。其它类型（图像、遮罩、音频、字典等）不会计数。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `text_1` | 可选 | ANY (`*`) | - | - | 第一个文本类输入；连接后前端会自动追加 `text_2..text_N` |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `int` | INT | 非空文本类输入数量 |

## 功能说明

- 动态输入：连接最后一个 `text_X` 端口后会自动追加下一个文本端口。
- 通配端口：STRING、INT、FLOAT（BOOLEAN 按整数处理）都可以接入同一组端口。
- 空值判定与 `Any Empty Bool` 一致：`""`、纯空白字符串、`0`、`0.0`、`False` 视为空。
- 列表感知：字符串列表（OUTPUT_IS_LIST，如 `List Custom String`）按非空元素逐项统计。
- 单次统计：列表输入在同一次执行内统计，不会按元素映射成多个整数输出。

## 典型用法

- 可选文本数量：统计实际提供了多少条参考文本或数值参数。
- 动态参数：用非空文本输入数量驱动下游整数参数。

## 注意事项

- 因为 `0` 视为空，数值 0 会被当作"未提供"；如果需要不同的映射，请使用 `Any Empty Int`。
- 非文本值会被忽略而不会报错，误接的 IMAGE/MASK 不会贡献计数。
- 统计的是输入个数，不是字符数或行数。
