# String Resolution Seedance 2.5 Multimodal Video - Seedance 2.5 多模态视频分辨率选择器

**节点功能：** `String Resolution Seedance 2.5 Multimodal Video` 根据输入视频的像素面积输出最接近的 Seedance 2.5 分辨率档位标签（`480p` / `720p` / `1080p` / `2k` / `4k`）；如果未连接视频，则直接输出手动选择的标签。与 ComfyUI-1hewOffice 的 `RunningHub Seedance 2.5 Multimodal Video`（`nodes/api/runninghub/runninghub_seedance_25_multimodal_video.py`）成对使用。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `selection` | - | COMBO | `480p` | `480p` / `720p` / `1080p` / `2k` / `4k` | 手动选择的分辨率标签；未连接 `video` 时直接输出此值 |
| `video` | 可选 | VIDEO | - | - | 输入视频，用于推断最接近的分辨率档位 |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `string` | STRING | 分辨率标签字符串，可直接接到 API 节点的 `resolution` 入端 |

## 档位与目标面积

| 档位 | 16:9 标准尺寸 | 目标面积（像素） |
| ---- | ------------- | ---------------- |
| `480p` | `854x480` | 409,920 |
| `720p` | `1280x720` | 921,600 |
| `1080p` | `1920x1080` | 2,073,600 |
| `2k` | `2560x1440` | 3,686,400 |
| `4k` | `3840x2160` | 8,294,400 |

## 功能说明

- 档位：`480p` / `720p` / `1080p` / `2k` / `4k`，与 Seedance 2.5 多模态视频节点 `resolution` 的常规档位一致（`native1080p` 不参与判断）。
- 面积匹配：按视频总像素面积在各档位目标面积中选择最近值（对数距离），与同系列的 `String Resolution` 图像节点一致。
- 竖屏正确：按面积而不是单边判断，`1080x1920` 等竖屏视频同样判为 `1080p`。
- 手动回退：未连接视频、或无法读取视频尺寸时，直接透传手动选择的标签。

## 典型用法

- 把输入视频同时接到本节点和 Seedance 2.5 多模态视频节点的参考视频入端，本节点输出接到 `resolution` 入端，即可让生成分辨率贴近素材。
- 不连接 `video` 时，可直接当作固定分辨率字符串选择器使用。

## 注意与建议

- 匹配依据是总像素面积，不考虑具体宽高比。
- 目标面积取各档 16:9 标准尺寸，`2k` 以 `2560x1440` 为准。
- 该节点只输出字符串标签，不会修改视频分辨率，也不会触发任何网络请求。
