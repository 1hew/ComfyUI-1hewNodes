# String Resolution Jimeng - 即梦分辨率选择器

**节点功能：** `String Resolution Jimeng` 根据输入图像面积输出最接近的即梦分辨率档位标签（`1k` / `2k` / `4k`）；如果未连接图像，则直接输出手动选择的标签。与即梦系列节点（jimeng_image_30 等，属于 ComfyUI-1hewJimeng）及本仓库的 `Image Resize Jimeng` 成对使用。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `selection` | - | COMBO | `1k` | `1k` / `2k` / `4k` | 手动选择的即梦分辨率标签；未连接 `image` 时直接输出此值 |
| `image` | 可选 | IMAGE | - | - | 输入图像批次，用于逐张推断最接近的分辨率档位 |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `string` | STRING | 分辨率标签字符串；批量输入时按批次顺序以换行拼接输出 |

## 档位与目标面积

| 档位 | 1:1 官方尺寸 | 目标面积（像素） |
| ---- | ------------ | ---------------- |
| `1k` | `1328x1328` | 1,763,584 |
| `2k` | `2048x2048` | 4,194,304 |
| `4k` | `4096x4096` | 16,777,216 |

## 按节点/模型可用的档位

即梦各节点的 `resolution` 选项由节点分别定义、并不统一，本节点输出的是并集；请选择与当前节点/模型匹配的档位：

| 即梦节点 | 可用档位 |
| -------- | -------- |
| `Jimeng Image T2I` | `1k` / `2k` / `4k` |
| `Jimeng Image Multi Edit` | `2k` / `4k` |
| `Jimeng Image 4.0` / `4.1` / `4.5` / `4.6` / `4.7` / `5.0 Lite` | `2k` / `4k` |
| `Jimeng Image 3.0` / `ControlNet` / `IP` | `1k` / `2k` |
| `Jimeng Image Single Edit` / `Style` / `Subject` | `1k` / `2k` |

- 模型 `2.0_pro` 不按 `1k` / `2k` / `4k` 分档，而是使用独立的 1024 基准尺寸表（`config.json` 的 `2.0_pro_ratios`）；此时 `resolution` 标签不改变尺寸分组，故不在本节点范围内。

## 功能说明

- 即梦档位：`1k` / `2k` / `4k`，按各档 1:1 官方尺寸的面积作为目标值。
- 面积匹配：按图像总像素面积在各档位目标面积中选择最近值（对数距离）。
- 手动回退：未连接图像时直接透传手动选择的标签。
- 支持批处理：图像批次中的每张图都会输出一行分辨率标签。

## 典型用法

- 在需要分辨率字符串参数的即梦节点前，把图像尺寸转换成分辨率标签，接到 API 节点的 `resolution` 入端。
- 不连接 `image` 时，可直接当作固定分辨率字符串选择器使用。

## 注意与建议

- 匹配依据是总像素面积，不考虑具体宽高比。
- 目标面积逐项对应即梦各档 1:1 官方尺寸（`ComfyUI-1hewJimeng` 的 `config.json` 中 `1k_ratios` / `2k_ratios` / `4k_ratios` 的 `1:1` 项，由 `core/utils_common.py` 的 `get_ratio_dimensions()` 读取）；该来源属于 ComfyUI-1hewJimeng（即梦插件），其源码不在本仓库内。
- 该节点只输出字符串标签，不会修改图像尺寸。
