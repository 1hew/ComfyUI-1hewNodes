# String Ratio Qwen Image 3.0 Pro - 千问图像 3.0 Pro 比例选择器

**节点功能：** `String Ratio Qwen Image 3.0 Pro` 为每张输入图像输出最接近的 Qwen Image 3.0 Pro 支持比例字符串；如果未连接图像，则直接输出手动选择的比例。与 1hewOffice 的 `Qwen Image 3.0 Pro` API 节点成对使用。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `selection` | - | COMBO | `1:1` | `3:1` / `21:9` / `2:1` / `16:9` / `3:2` / `4:3` / `5:4` / `1:1` / `4:5` / `3:4` / `2:3` / `9:16` / `1:2` / `9:21` / `1:3` | 手动选择的 Qwen Image 3.0 Pro 比例预设；未连接 `image` 时直接输出此值 |
| `image` | 可选 | IMAGE | - | - | 输入图像批次，用于逐张推断最接近的支持比例 |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `string` | STRING | 比例字符串结果；批量输入时按批次顺序以换行拼接输出 |

## 功能说明

- Qwen Image 3.0 Pro 比例集：`3:1`、`21:9`、`2:1`、`16:9`、`3:2`、`4:3`、`5:4`、`1:1`、`4:5`、`3:4`、`2:3`、`9:16`、`1:2`、`9:21`、`1:3`，共 15 个。
- 图像驱动推断：基于对数比例差匹配每张输入图最接近的预设宽高比。
- 手动回退：未连接图像时直接透传手动选择的比例。
- 批处理友好：支持图像批次输入，每张图输出一行比例字符串。

## 典型用法

- 用在需要比例字符串输入的 Qwen Image 3.0 Pro 图像节点前：把本节点 `string` 输出接到 API 节点的 `aspect_ratio` 入端。
- 当你希望下游固定使用某个比例时，可以不连接 `image`，直接输出选定值。
- 也可以把同一张参考图接到 API 节点的 `get_image_size`，让 API 节点的 `aspect_ratio=auto` 自行推断比例；本节点适合需要显式拿到比例字符串（记录、转发或做条件判断）的场景。

## 注意与建议

- 这个节点只输出比例字符串，不会修改图像尺寸；出图像素由 API 节点的 `resolution`（`1k` / `2k`）与比例查官方尺寸表决定。
- 比例集合**逐项等同**于 1hewOffice 的 `Qwen Image 3.0 Pro` API 节点中 `QwenImage30Pro.ASPECT_RATIO_OPTIONS` 去掉 `auto` / `dynamic` 后的 15 项，已逐项核对一致；该 API 节点属于 1hewOffice，其源码不在本仓库内。与本仓库 `Image Resize Qwen Image 3.0 Pro` 的预设比例表也完全一致。
- 这里不提供 `auto` / `dynamic`：两者由 API 节点自行按参考图/提示词推断，本节点输出的是可直接使用的具体比例。
- API 节点的图生图（`/v1/images/edits`）链路会被上游忽略 `size`、输出约 2K 并跟随参考图比例，因此本节点主要对**文生图**生效。
- 返回的比例为按对数比例差最接近的预设项；Qwen Image 3.0 Pro 官方支持 `1:8` ~ `8:1`，超出 15 档的更极端比例会被吸附到最接近的一档。
