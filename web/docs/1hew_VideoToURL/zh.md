# Video to URL - 视频转 URL

**节点功能：** `Video to URL` 将 ComfyUI `VIDEO` 对象上传到 `kefan.cn`，返回可直接传递给下游节点或外部 API 的公网 URL 字符串。

## 输入

| 参数名称 | 入端选择 | 数据类型 | 默认值 | 取值范围 | 描述 |
| -------- | -------- | -------- | ------ | -------- | ---- |
| `video` | - | VIDEO | - | - | 输入视频；可选，未连接时输出为空字符串 |
| `timeout` | - | INT | 30 | 5-300 | 上传请求超时时间（秒） |

## 输出

| 输出名称 | 数据类型 | 描述 |
|---------|----------|------|
| `url` | STRING | 上传后得到的公网 URL；未连接视频时输出为空字符串 |

## 功能说明

- 将视频上传到 `kefan.cn`，返回对应的公网 URL。
- 带缓存复用：相同视频内容重复上传时会优先复用缓存映射，减少重复上传。
- 输入可选：当 `video` 未连接时，节点返回空字符串而不是报错。
- 上传失败时（例如网络异常或第三方服务不可用）会抛出错误。

## 典型用法

- 将加载或生成的 `VIDEO` 对象转换为公网 URL，供只接受公网视频链接的下游服务使用。
- 与 `Load Video` 或 `Save Video` 等工作流配合，将视频交给外部 API 处理。

## 注意与建议

- 上传依赖外网访问与第三方上传服务的可用性。
- 视频文件通常远大于图片，上传耗时更长，可通过 `timeout` 参数调整超时上限。
